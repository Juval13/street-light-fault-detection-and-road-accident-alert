# Frontend for Street Light Fault Detection & Road Accident Alert

This is a React-based frontend with a login page and dashboard.

## Getting Started

1. Install dependencies:
   npm install

2. Start the development server:
   npm start

- Login with username: admin, password: admin (demo only)
- The dashboard is a placeholder for future widgets and data.

## Project Structure
- public/index.html: HTML template
- src/index.js: Entry point
- src/App.jsx: Main app with routing
- src/Login.jsx: Login page
- src/Dashboard.jsx: Dashboard page
- src/styles.css: Basic styles

## Build
npm run build

---

For backend integration, connect API calls in the dashboard and login components.
